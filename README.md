## Giới Thiệu Dự Án
Dự án thực hành các thao tác quản lý phiên bản với Git và GitHub:
1. Khởi tạo kho chứa cục bộ (Local Repository) và liên kết với GitHub (Remote Repository).
2. Tạo và quản lý các commit cơ bản trên nhánh `main`.
3. Phân nhánh (Branching) với nhánh `feature/them-giao-dien`.
4. Gộp nhánh (Merging) vào nhánh chính và đẩy mã nguồn lên GitHub.
